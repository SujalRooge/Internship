# Assignment: Component Hunt

## Description
In this assignment, a popular website is analyzed and broken down into smaller UI components to understand how modern websites are structured. Component-based design is widely used in web development frameworks, where a webpage is divided into reusable parts such as headers, navigation bars, content sections, and footers.

For this assignment, the YouTube website was selected and its interface was divided into multiple components based on its layout and functionality. Each component represents a specific part of the webpage that performs a particular task.

## Website Chosen
YouTube

## Identified Components

### 1. Header (Top Navigation Bar)
- Logo
- Search bar
- Voice search icon
- Create button
- Notifications icon
- User profile icon

### 2. Sidebar
- Home
- Shorts
- Subscriptions
- Library
- History
- Trending

### 3. Main Content Area
- Video grid layout
- Recommended videos
- Video thumbnails

### 4. Video Card Component
Each video card contains:
- Thumbnail image
- Video title
- Channel name
- Views
- Upload time

### 5. Footer
- About
- Help
- Privacy
- Terms
- Contact information
